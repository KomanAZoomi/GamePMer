# GamePMer 实施决策记录

## ADR-001：M1 本地数据库加密依赖

**日期：** 2026-07-15  
**状态：** 已接受风险，M1 生效

M1 使用 `SQLitePCLRaw.bundle_e_sqlcipher` 2.1.11 为本地 SQLite 数据库提供 SQLCipher 兼容加密。该包已停止维护；项目负责人明确接受该风险，并将在后续版本自行维护、替换或迁移至公司批准的受维护提供程序。

实施与发布必须满足以下门槛：

- 数据库文件、WAL 与 SHM 不得以明文泄露业务内容。
- 无密钥和错误密钥均无法读取数据库。
- 每次迁移前自动备份；备份、恢复和迁移包导入必须通过验证。
- 任何依赖升级均在隔离副本上完成加密兼容性和恢复演练后才能发布。
- 更换提供程序时，保留可读旧库的迁移工具与回滚包。

## ADR-002：受支持的 Windows 设备

**日期：** 2026-07-15  
**状态：** 已接受

正式支持 Windows 11 x64。Windows 10 仅限公司仍在 ESU 或 LTSC 支持周期内、并由 IT 管理的设备；普通 Windows 10 22H2 不作为发布验证目标。
