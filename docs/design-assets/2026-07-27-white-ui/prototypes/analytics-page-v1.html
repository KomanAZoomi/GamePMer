  1. 延期归因分四类：客户等待 / 范围内返修 / 团队延期 / 依赖阻塞。够不够？还是要拆得更细（比如「等报价复核」「等素材」单独算）？这四类会一路用到甘特、任务和报表，改起来成本不低，现在定比较好。
