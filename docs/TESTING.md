# Web Demo 验收

在 `apps/gamepmer-web` 目录执行：

```powershell
npm install
npm test
npm run lint
npm run build
npm run dev
```

五分钟手工验收：

1. 打开页面，确认左侧有 `P-3D-024`、`P-2D-018`、`P-3D-031`，中间显示 MECH-01 的六个 PBR 节点。
2. 在右侧反馈 `F-017` 点击“查看影响并生成草案”。
3. 确认高模及下游节点变为琥珀色重排草案，且右侧显示新的工作日日期。
4. 拖动一个琥珀色条形到相邻日期列，或点击该节点的 `+1 天`，确认只有草案日期改变。
5. 点击“确认 5 项排期修订”，确认页面显示“已确认 1 次修订”。刷新页面后修订仍存在。

所有演示数据均为虚构。浏览器不会发送邮件、调用聊天平台或操作任何文件。
