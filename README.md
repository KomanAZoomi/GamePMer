# GamePMer

面向游戏美术 PM 的内网 Web 工作台。当前版本是一个可独立演示的“客户反馈导致排期重排”垂直切片。

它刻意不接入真实邮件、企微、飞书或文件盘；所有项目、客户、资产与消息均为虚构演示数据。

## 当前 Demo

- 预置 2D 与 3D 项目；`MECH-01` 包含中模、高模、低模、烘焙、贴图、LOD 六个 PBR 阶段。
- 展示反馈 `F-017`：高模肩甲比例返修，增加 2 个工作日。
- 自动生成琥珀色的工作日重排草案；正式基线不被修改。
- PM 可直接拖动草案条形或以工作日微调；仅在确认后写入当前排期。
- 确认后创建一条修订记录及给组长、艺术总监的“待发送”通知草稿。
- 浏览器本地保存已确认修订；不执行任何真实外部操作。

## 本地运行

```powershell
cd apps/gamepmer-web
npm install
npm run dev
```

打开终端显示的本地地址。详细验收脚本见 [docs/TESTING.md](docs/TESTING.md)。
